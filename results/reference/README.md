# Manuscript reference values

`paper_claims.yaml` transcribes selected values stated in the supplied
manuscript. These entries are **not raw data**, **not generated results**, and
**not loaded by training or evaluation code**. They exist only so a completed
five-seed run can be compared manually with the paper.

Never copy these values into `results/generated/`. Numerical reproduction
requires preserved per-seed logs and a computed mean/standard deviation.
